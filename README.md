# Cotizador de Sistemas Fotovoltaicos

Proyecto desarrollado como parte del Bootcamp Full Stack Python.

El objetivo del proyecto es construir un sistema SaaS para generar
cotizaciones de sistemas fotovoltaicos.

## Stack

- Python 3.13
- Django 6.1
- PostgreSQL 16
- Bootstrap 5
- jQuery 4
- Docker
- Dev Containers
