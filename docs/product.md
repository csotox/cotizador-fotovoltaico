# Producto

## ¿Qué problema resuelve?

Permitir generar cotizaciones de sistemas fotovoltaicos de forma simple y consistente.

## Usuario objetivo
Empresa o vendedor que necesita preparar una cotización para un cliente.

## País de operación
El sistema está diseñado para operar en Chile. El contexto chileno considera la validación de RUT, las comunas del país, la moneda CLP y la zona horaria `America/Santiago`.

En este sistema, una **compañía** es la organización que emite las cotizaciones. Un cliente puede ser una persona natural o una persona jurídica (una empresa a la que se emite una cotización).

La forma de pago de un cliente registra una preferencia comercial; no implica procesamiento de pagos, que permanece fuera del MVP.


## Objetivo principal

Ingresar datos básicos del cliente y del proyecto para obtener una cotización fotovoltaica.

## Alcance del MVP

- Gestionar compañias.
- Gestionar clientes.
- Gestionar productos principales.
- Crear cotizaciones.
- Calcular totales.
- Visualizar una cotización.
- Mantener historial de cotizaciones.

## Fuera del MVP

- Pagos.
- App móvil.
