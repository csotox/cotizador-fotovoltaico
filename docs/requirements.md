# Requisitos funcionales

## Cuenta y empresa

- ADR-001: El sistema debe permitir registrar un usuario.
- ADR-002: El sistema debe permitir iniciar y cerrar sesión.
- ADR-003: El sistema debe asociar cada usuario a una empresa.
- ADR-004: El sistema debe impedir que un usuario acceda a datos de otra empresa.

## Clientes

- ADR-005: El sistema debe permitir registrar clientes.
- ADR-006: El sistema debe permitir editar clientes.
- ADR-007: El sistema debe permitir consultar clientes.

## Productos

- ADR-008: El sistema debe permitir registrar productos utilizados en sistemas fotovoltaicos.
- ADR-009: El sistema debe permitir editar productos.
- ADR-010: El sistema debe permitir consultar productos.

## Cotizaciones
- ADR-011: El sistema debe permitir crear una cotización para un cliente.
- ADR-012: El sistema debe permitir agregar productos a una cotización.
- ADR-013: El sistema debe calcular el total de la cotización.
- ADR-014: El sistema debe permitir visualizar una cotización.
- ADR-015: El sistema debe mantener historial de cotizaciones.
